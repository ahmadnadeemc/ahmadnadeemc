## Featured project

### [Kestrel Supply Co.](https://github.com/ahmadnadeemc/kestrel-store) — e-commerce storefront
**[Live demo →](https://ahmadnadeemc.github.io/kestrel-store/)**

A full storefront in plain HTML, CSS and JavaScript: filterable catalogue, live search, product pages with spec sheets, a cart drawer with promo codes, checkout, saved items and a light/dark theme — all persisted between visits. No framework, no build step, no dependencies, and every product illustration drawn as inline SVG from the same theme tokens as the UI.
