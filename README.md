## Featured projects

### [Kestrel Supply Co.](https://github.com/ahmadnadeemc/kestrel-store) — e-commerce storefront
**[Live demo →](https://ahmadnadeemc.github.io/kestrel-store/)**

A full storefront in plain HTML, CSS and JavaScript: filterable catalogue, live search, product pages with spec sheets, a cart drawer with promo codes, checkout, saved items and a light/dark theme — all persisted between visits. No framework, no build step, no dependencies, and every product illustration drawn as inline SVG from the same theme tokens as the UI.

`HTML` · `CSS` · `JavaScript` · `Responsive design` · `Accessibility` · `GitHub Pages`

### [Cadence CRM](https://github.com/ahmadnadeemc/cadence-crm) — sales pipeline tool
**[Live demo →](https://ahmadnadeemc.github.io/cadence-crm/)**

A CRM for a small sales team: a drag-and-drop pipeline board across five stages, a dashboard with weighted forecasting against target, a sortable and filterable deals table, deal records with full history, contacts, accounts and tasks. Moving a card updates the stage, the probability and the activity log at once, so the board and the forecast can never disagree.

`HTML` · `CSS` · `JavaScript` · `Drag and drop` · `Data visualization` · `localStorage`
